### 4.3 预期大小

| 组件 | 大小 |
|---|---|

### 4.4 可使用的一键打包脚本 (`build.bat`)

```bat
@echo off
chcp 65001 >nul
cd /d "%~dp0"

echo ========================================
echo   AVT Subtitle Processor — 打包构建
echo ========================================

REM 设置 Python 路径
set PYTHON=D:\Software\PaddleOCR_gpu\venv\Scripts\python.exe

REM 步骤 1: 清理旧构建
echo [1/3] 清理旧构建产物...
if exist dist rmdir /s /q dist
if exist build rmdir /s /q build

REM 步骤 2: PyInstaller 打包
echo [2/3] PyInstaller 打包中...
%PYTHON% -m PyInstaller AVT_Subtitle_Processor.spec --clean --noconfirm
if %errorlevel% neq 0 (
    echo [ERROR] 打包失败!
    pause
    exit /b 1
)

REM 步骤 3: 验证
echo [3/3] 验证打包结果...
if exist "dist\AVT_Subtitle_Processor\AVT_Subtitle_Processor.exe" (
    echo [OK] AVT_Subtitle_Processor.exe
) else (
    echo [ERROR] AVT_Subtitle_Processor.exe 缺失!
)
if exist "dist\AVT_Subtitle_Processor\_internal\bin\ffmpeg.exe" (
    echo [OK] ffmpeg.exe
) else (
    echo [ERROR] ffmpeg.exe 缺失!
)

echo ========================================
echo   打包完成!
echo ========================================
pause
```

## 5. 关键配置说明

### 5.1 `.spec` 文件核心架构

[AVT_Subtitle_Processor.spec](../AVT_Subtitle_Processor.spec) 采用 **四阶段** 打包策略：

| 阶段 | 机制 | 说明 |
|---|---|---|
| **Analysis** | `hiddenimports` 列表 (90+ 项) | 让 PyInstaller 分析并收集模块到 PYZ |
| **EXE** | 生成 `.exe` 和 `.pkg` | 创建可执行入口 |
| **COLLECT** | PyInstaller 内置收集 | 将 PYZ/DLL/数据文件聚合到 `_internal/` |
| **post-COLLECT** | 自定义 Python 代码 | 复制被 PyInstaller 排除或遗漏的模块/文件 |

### 5.2 为什么需要 post-COLLECT 复制

以下模块无法通过 PyInstaller 的 `hiddenimports` 或 `datas` 自动收集：

| 模块 | PyInstaller 限制 | 解决方案 |
|---|---|---|
| `unittest` | 硬编码排除（内置 hook 禁止收集标准测试库） | post-COLLECT 从 `sys.base_prefix/Lib/unittest` 复制 |
| `Cython/Utility/` | Cython 的 C++ 模板文件，PyInstaller 不识别的非 Python 数据 | post-COLLECT 从 venv 复制 |
| `paddle/` (完整) | PyInstaller 只收集部分到 PYZ，42 个子目录中仅约 2 个被提取 | post-COLLECT 从 venv 补充缺失子目录 |
| `paddleocr/` | 被压缩到 PYZ 中，但某些加载路径需要文件系统访问 | post-COLLECT 从 venv 完整复制 |
| `nvidia/` | CUDA 模块的 Python 包装（DLL 由系统 PATH 加载） | post-COLLECT 从 venv 复制容器结构 |
| `imgaug/` | 包含非 Python 数据文件（.ttf、.jpg） | post-COLLECT 从 venv 复制 |
| `bin/ffmpeg.exe` | `a.datas` 参数在某些 PyInstaller 版本中完全失效 | post-COLLECT 从 `PROJECT_ROOT/bin/` 复制 |

### 5.3 路径解析机制

打包后的运行时路径解析流程（[config_manager.py](../modules/config_manager.py) / [subtitle_engine.py](../modules/subtitle_engine.py)）：

```
配置值: ./bin/ffmpeg.exe
         ↓
get_base_dir() → sys._MEIPASS (frozen) 或 os.path.dirname(caller) (dev)
         ↓
_resolve_tool_path() → 三层降级:
  1. sys._MEIPASS + 相对路径  → _internal/bin/ffmpeg.exe
  2. base_dir + 相对路径      → exe_dir/bin/ffmpeg.exe
  3. base_dir + _internal + 相对路径 → exe_dir/_internal/bin/ffmpeg.exe
         ↓
返回最先存在的可执行文件路径
```

### 5.4 关键 `sys` 变量

在 `PyInstaller` spec 文件中：

| 变量 | 含义 | 示例值 |
|---|---|---|
| `SPECPATH` | spec 文件所在目录（项目根目录） | `D:\...\AVT_subtitle_processor` |
| `sys.executable` | 当前 Python 解释器路径 | `D:\Software\PaddleOCR_gpu\venv\Scripts\python.exe` |
| `sys.base_prefix` | 基础 Python 安装目录 | `C:\Users\...\AppData\Local\Programs\Python\Python312` |

## 6. 已知问题与解决方案

### 6.1 `ModuleNotFoundError: No module named 'unittest'`

**现象**：PaddleOCR 初始化时报错 `from unittest.mock import Mock`

**根因**：PyInstaller 有内置 hook 硬编码排除 `unittest`，`hiddenimports` 无法覆盖。

**解决**：在 spec 的 post-COLLECT 阶段从 `sys.base_prefix/Lib/unittest` 复制整个模块。

### 6.2 `FileNotFoundError: Cython/Utility/CppSupport.cpp`

**现象**：PaddleOCR 加载 Cython 编译器时报找不到 `.cpp` 文件

**根因**：Cython/Utility 目录包含 C++ 模板文件，PyInstaller 不会自动收集非 Python 数据文件。

**解决**：post-COLLECT 从 venv 复制 `Cython/Utility/`。

### 6.3 `[WinError 5] 拒绝访问` (FFmpeg 执行)

**现象**：FFmpeg 检查阶段返回拒绝访问错误

**根因**：两种情况：
1. `a.datas.append()` 使 COLLECT 将 `bin/ffmpeg.exe` 创建为**目录**，而非文件
2. `subprocess.run()` 对目录路径返回 `ERROR_ACCESS_DENIED`

**解决**：
- 移除 `a.datas.append()` 中的 bin 文件条目
- post-COLLECT 复制时检测并 `rmtree` 清理残留目录

### 6.4 `paddle/` 子目录严重缺失

**现象**：paddle 目录仅有 `base/` 和 `libs/`，缺失 40 个子目录

**根因**：PyInstaller 将 paddle 模块压缩到 PYZ 中，但部分 Paddle 内部代码依赖文件系统路径。

**解决**：post-COLLECT 从 venv 补充所有缺失的 paddle 子目录。

### 6.5 `--hidden-import` vs `hiddenimports` (spec)

**说明**：spec 文件中的 `hiddenimports` 列表效果等同于命令行 `--hidden-import`。
但 `unittest` 等被硬编码排除的模块二者均无法生效，必须用数据文件复制方式。

### 6.6 非关键警告（可忽略）

以下警告始终出现，属于 PyInstaller 的正常行为：

| 警告 | 原因 |
|---|---|
| `Hidden import "sip" not found` | sip 已作为 PyQt5 编译模块收集 |
| `Hidden import "scipy.special._cdflib" not found` | 已作为 C 扩展 .pyd 收集 |
| `Hidden import "unittest.mock" not found` | unittest 被硬编码排除，但 post-COLLECT 已复制 |

### 6.7 dist 中残留 `__pycache__` 和 `.pyc` 文件

**现象**：打包后 `_internal/` 中某些目录下残留 `__pycache__/` 或 `.pyc` 字节码缓存。

**根因**：PyInstaller 的 COLLECT 阶段可能生成 `__pycache__`，post-COLLECT 复制 venv 模块时也可能带入。

**解决**：`.spec` 的 post-COLLECT 步骤 10 在复制完成后统一清理所有 `__pycache__/` 目录和 `.pyc/.pyo` 文件。

### 6.8 项目 `__pycache__` 缓存文件

## 8. 故障排查指南

### 8.1 打包失败：PermissionError

**症状**：`PermissionError: [WinError 5] 拒绝访问`

**原因**：dist 目录中的文件被进程锁定（例如正在运行的程序或杀毒软件扫描）

**解决**：
```powershell
# 结束所有 AVT 进程
Get-Process AVT* | Stop-Process -Force
# 重新清理
Remove-Item .\dist -Recurse -Force
Remove-Item .\build -Recurse -Force
# 重试打包
```

### 8.2 打包后 FFmpeg 路径错误

**症状**：日志显示 FFmpeg 未找到，路径在 `exe_dir\bin\` 而非 `_internal\bin\`

**诊断**：检查 `config_manager.py` 中的 `get_base_dir()` 是否返回 `sys._MEIPASS`

**验证**：
```powershell
# 用 Console 版本查看日志
.\dist\AVT_Subtitle_Processor\AVT_Subtitle_Processor_Console.exe
```

### 8.3 模块缺失但未被检测

**症状**：程序在特定功能时报 `ModuleNotFoundError`

**诊断**：
1. 检查 `_internal/` 中是否有对应模块目录
2. 对比老版本（`d:\Users\liket\Desktop\AVT\AT\AVT_Subtitle_Processor\_internal`）的模块清单

**解决**：在 spec 的 post-COLLECT 阶段添加复制步骤

### 8.4 dist 目录快速增长

**说明**：每次构建前必须手动清理 dist/build，或使用 `--clean` 参数

**最佳实践**：始终使用 `build.bat` 一键脚本，它会自动清理
