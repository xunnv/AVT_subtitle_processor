# AVT 字幕处理器 - 外部依赖说明

## ✅ 不需要安装 Python！

本程序已经使用 PyInstaller 打包，包含了完整的运行环境，**无需安装 Python 即可运行！**

---

## 🔴 必需外部工具（不包含在Python包中）

### 1. FFmpeg + FFprobe（绝对必需！没有它程序无法工作！

**下载地址：**
- 官方：https://www.gyan.dev/ffmpeg/builds/
- 推荐下载 "ffmpeg-git-full.7z"

**放置位置：**
将以下文件放在程序目录（与 `AVT_Subtitle_Processor.exe` 同级）：
- `ffmpeg.exe`
- `ffprobe.exe`

**验证安装：**
运行程序后，如果FFmpeg可用，应该能正常处理视频。

---

## 🟡 可选外部工具

### 2. 翻译后端（Ollama 或 LM Studio）

如果需要字幕翻译功能，需要安装以下其中之一：

#### 选项A: Ollama
- 下载：https://ollama.com/
- 安装后下载翻译模型：
  ```bash
  ollama pull quantumcookie/sakura-galtransl-v3.7:7b
  ```

#### 选项B: LM Studio
- 下载：https://lmstudio.ai/
- 在软件中搜索并下载：`sakura-galtransl-v3.7`

---

## 🟢 硬件/驱动要求

### 3. NVIDIA GPU + 驱动（推荐）
- 需要支持 CUDA 11.x 的 NVIDIA GPU 驱动
- 如果没有GPU，程序会自动切换到CPU模式

---

## 📦 完整分发包结构

```
AVT_Subtitle_Processor/
├── AVT_Subtitle_Processor.exe
├── bin/
│   ├── ffmpeg.exe            ← 放在这里！
│   └── ffprobe.exe           ← 放在这里！
├── config/
│   └── config.json
└── _internal/                ← PyInstaller打包的依赖
```

---

## 🚀 快速开始

1. 下载 FFmpeg，解压后把 `ffmpeg.exe` 和 `ffprobe.exe` 放到 `bin/` 目录
2. （可选）安装并启动 Ollama/LM Studio
3. 运行 `AVT_Subtitle_Processor.exe`
