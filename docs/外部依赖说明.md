# AVT 字幕处理器 — 外部依赖说明

## 用户端（使用打包后的 exe）

打包后的程序包含完整运行环境，**无需安装 Python**。

### FFmpeg（已内置）

FFmpeg 已随程序打包至 `_internal/bin/`，首次启动自动检测，无需手动配置。

### NVIDIA GPU 驱动（推荐）

| 要求 | 说明 |
|---|---|
| NVIDIA 驱动 | 需支持 CUDA 12.x |
| CUDA Toolkit | 程序自动从系统 CUDA 路径加载 DLL，无需手动安装 |
| 无 GPU 时 | 自动降级为 CPU 模式（速度较慢） |

### 翻译后端（可选）

翻译功能需用户自行安装以下之一：

| 后端 | 下载 | 模型 |
|---|---|---|
| Ollama | https://ollama.com/ | `ollama pull quantumcookie/sakura-galtransl-v3.7:7b` |
| LM Studio | https://lmstudio.ai/ | 搜索 `sakura-galtransl-v3.7` |

## 开发者端（开发环境）

### 必需

| 组件 | 版本 | 说明 |
|---|---|---|
| Python | 3.12.x | 运行环境 |
| NVIDIA CUDA Toolkit | 12.x | GPU 加速 |
| NVIDIA cuDNN | 9.x | 深度学习加速 |
| FFmpeg | 8.1.1+ | 视频处理（放置于项目 `bin/`） |
| Visual C++ Redistributable | 2015-2022 | 运行时库（程序启动时自动检测提示） |

### Python 依赖

完整依赖清单参见 [requirements.txt](../requirements.txt)。关键框架：

| 依赖 | 版本 | 用途 |
|---|---|---|
| PyQt5 | ≥5.15.10 | GUI 框架 |
| paddlepaddle-gpu | ≥3.3.0 | 深度学习框架 |
| paddleocr | ≥2.8.1 | OCR 引擎 |
| opencv-python | ≥4.10.0 | 图像处理 |
| PyInstaller | ≥6.3.0 | 打包工具 |

### 打包注意事项

详见 [打包指南](打包指南.md)。打包时需注意以下模块因 PyInstaller 硬编码排除，必须通过 post-COLLECT 复制：

- `unittest` — Paddle cpp_extension 依赖
- `Cython/Utility/` — C++ 模板文件
- `paddleocr/` — 完整模块目录
- `paddle/` — 补充缺失子目录
- `imgaug/` — 图像增强模块
- `nvidia/` — CUDA 模块容器
