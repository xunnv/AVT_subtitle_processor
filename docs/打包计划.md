## 4. 打包流程步骤

### 4.1 步骤总览

```
步骤 1: 环境准备
    ↓
步骤 2: 清理旧构建
    ↓
步骤 3: 执行打包命令
    ↓
步骤 4: 复制资源文件
    ↓
步骤 5: 创建分发包
    ↓
步骤 6: 验证打包结果
```

### 4.2 详细步骤

#### 步骤 1：环境准备

```bash
# 激活虚拟环境
& "D:\Software\PaddleOCR_gpu\venv\Scripts\Activate.ps1"

# 切换到项目目录
cd D:\Users\liket\Desktop\AVT\AVT_subtitle_processor
```

#### 步骤 2：清理旧构建

```bash
Remove-Item -Recurse -Force dist -ErrorAction SilentlyContinue
Remove-Item -Recurse -Force build -ErrorAction SilentlyContinue
Remove-Item -Force AVT_Subtitle_Processor.spec -ErrorAction SilentlyContinue
```

#### 步骤 3：执行打包命令

```bash
# 核心打包命令
pyinstaller ^
    --name=AVT_Subtitle_Processor ^
    --windowed ^
    --onedir ^
    --collect-all paddleocr ^
    --collect-all pyclipper ^
    --collect-all lmdb ^
    --collect-all paddle ^
    --collect-all PyQt5 ^
    --add-data "config;config" ^
    --add-data "bin;bin" ^
    main.py
```

#### 步骤 4：复制资源文件

```bash
# 确保配置目录存在
mkdir -Force dist\AVT_Subtitle_Processor\config

# 复制配置模板（首次运行会自动复制为 config.json）
Copy-Item config\config.example.json dist\AVT_Subtitle_Processor\config\ -Force

# 创建必要的目录
mkdir -Force dist\AVT_Subtitle_Processor\videos
mkdir -Force dist\AVT_Subtitle_Processor\output
mkdir -Force dist\AVT_Subtitle_Processor\logs
```

#### 步骤 5：创建分发包

```bash
# 使用 7-Zip 创建自解压压缩包
# 下载地址：https://www.7-zip.org/

# 创建压缩包
& "C:\Program Files\7-Zip\7z.exe" a ^
    -t7z ^
    -mx9 ^
    -sfx ^
    -iicon:icon.ico ^
    "AVT_Subtitle_Processor_Setup.exe" ^
    "dist\AVT_Subtitle_Processor\"
```

## 5. 资源文件处理方式

### 5.1 资源文件列表

| 资源 | 源路径 | 目标路径 | 处理方式 |
|------|--------|---------|---------|
| **ffmpeg.exe** | `bin/` | `dist/AVT_Subtitle_Processor/bin/` | `--add-data` |

| **配置模板** | `config/config.example.json` | `dist/AVT_Subtitle_Processor/config/` | 手动复制 |

### 5.2 路径自动检测

程序内部实现自动路径检测，确保打包后能正确找到资源：

```python
import sys
import os

def get_app_path():
    """获取程序运行目录（兼容开发和打包后）"""
    if getattr(sys, 'frozen', False):
        # 打包后运行
        return os.path.dirname(sys.executable)
    else:
        # 开发模式
        return os.path.dirname(os.path.abspath(__file__))

# 自动配置路径
app_path = get_app_path()
ffmpeg_path = os.path.join(app_path, 'bin', 'ffmpeg.exe')
config_path = os.path.join(app_path, 'config', 'config.json')
```

### 5.3 首次运行自动初始化

程序启动时自动检查并创建必要文件：

```python
def initialize_app():
    """首次运行初始化"""
    app_path = get_app_path()
    
    # 检查配置文件
    config_path = os.path.join(app_path, 'config', 'config.json')
    config_example = os.path.join(app_path, 'config', 'config.example.json')
    
    if not os.path.exists(config_path) and os.path.exists(config_example):
        # 复制配置模板
        shutil.copy(config_example, config_path)
        logger.info("配置文件已初始化")
    
    # 创建必要目录
    dirs = ['videos', 'output', 'logs']
    for dir_name in dirs:
        dir_path = os.path.join(app_path, dir_name)
        if not os.path.exists(dir_path):
            os.makedirs(dir_path)
            logger.info(f"创建目录: {dir_path}")
```

## 12. 常见问题及解决方案

### 问题 1：程序无法启动

**原因**：缺少 Microsoft Visual C++ 运行库

**解决方案**：
```
自动安装：程序启动时会提示安装
手动安装：下载并安装 VC Redist 2022
下载地址：https://aka.ms/vs/17/release/vc_redist.x64.exe
```

### 问题 2：OCR 识别失败

**原因**：GPU 不可用或 CUDA 版本不兼容

**解决方案**：
```
1. 确保安装了 NVIDIA 显卡驱动
2. 程序会自动检测并切换到 CPU 模式（速度较慢）
3. 推荐使用支持 CUDA 12.x 的 NVIDIA GPU
```

### 问题 3：字幕烧录失败

**原因**：FFmpeg 路径错误

**解决方案**：
```
程序已内置 FFmpeg，无需手动配置
如果仍失败，请检查 bin/ 目录是否包含 ffmpeg.exe
```

### 问题 4：程序启动慢

**原因**：首次运行需要初始化 OCR 模型

**解决方案**：
```
首次启动较慢是正常的（模型加载）
后续启动会更快
```

## 13. 附录：spec 文件配置示例

```python
# AVT_Subtitle_Processor.spec

a = Analysis(
    ['main.py'],
    pathex=['D:\\Users\\liket\\Desktop\\AVT\\AVT_subtitle_processor'],
    datas=[
        ('config', 'config'),
        ('bin', 'bin'),
    ],
    hiddenimports=[
        'paddleocr',
        'paddle',
        'pyclipper',
        'lmdb',
        'skimage',
        'imgaug',
    ],
    hookspath=[],
    runtime_hooks=[],
    excludes=[],
    win_no_prefer_redirects=False,
    win_private_assemblies=False,
)

pyz = PYZ(a.pure, a.zipped_data)

exe = EXE(
    pyz,
    a.scripts,
    [],
    exclude_binaries=True,
    name='AVT_Subtitle_Processor',
    debug=False,
    console=False,  # 窗口模式
    target_arch=None,
)

coll = COLLECT(
    exe,
    a.binaries,
    a.zipfiles,
    a.datas,
    name='AVT_Subtitle_Processor',
)
```
