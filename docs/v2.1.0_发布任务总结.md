## 4. 遇到的问题及解决

### 问题 1：push 被拒（分支冲突）
- **现象**：`[rejected] main -> main (fetch first)`
- **原因**：远程 origin/main 有新增的 CI/CD 提交（`.github/workflows/`），本地 rebase 时全部冲突
- **解决**：`git rebase --abort` → `git push -u origin main --force`

### 问题 2：workflow 权限拒绝
- **现象**：`refusing to allow a Personal Access Token to create or update workflow`
- **原因**：当前 PAT 缺少 `workflow` scope，无法推送 `.github/workflows/` 下的文件
- **解决**：`git rm --cached` 移出 CI/CD 文件后 push 成功
- **注意**：如需推送 workflow 文件，需在 GitHub 生成一个新的带 `workflow` scope 的 PAT

### 问题 3：Release 中文乱码
- **现象**：Release 说明中文显示为 `??`
- **根因**：PowerShell `Invoke-RestMethod` 的 `ConvertTo-Json` 默认将中文转义为 `\uXXXX`
- **解决**：改用 Python 脚本发送请求

```python
# 关键代码
import json, urllib.request

body = "中文内容..."
payload = json.dumps({"body": body}, ensure_ascii=False).encode("utf-8")

req = urllib.request.Request(url, data=payload, method="PATCH", headers={
    "Authorization": "token TOKEN",
    "Content-Type": "application/json; charset=utf-8"
})
urllib.request.urlopen(req)
```

- **核心**：`ensure_ascii=False` 阻止 JSON 序列化时转义非 ASCII 字符，配合 `Content-Type: charset=utf-8`

## 5. GitHub API Release 操作指南

### 创建 Release
```bash
POST https://api.github.com/repos/:owner/:repo/releases
Body: {"tag_name": "v2.1.0", "name": "v2.1.0", "body": "...", "draft": false, "prerelease": false}
Header: Authorization: token TOKEN
```

### 上传附件
```bash
POST https://uploads.github.com/repos/:owner/:repo/releases/:release_id/assets?name=文件.zip
Header: Authorization: token TOKEN, Content-Type: application/octet-stream
Body: 文件二进制内容
```

### 更新 Release 说明
```bash
PATCH https://api.github.com/repos/:owner/:repo/releases/:release_id
Body: {"body": "新的中文说明..."}
Header: Authorization: token TOKEN, Content-Type: application/json; charset=utf-8
```
